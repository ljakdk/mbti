# 🌈 나를 알아보는 성격 여행

초등학생을 위한 성격 알아보기(MBTI 놀이) 웹 프로그램입니다.
20개의 질문에 답하면 성격 유형, 강점, 키울 점, 어울리는 직업을 알려 줍니다.

**👉 바로 해 보기 :** https://ljakdk.github.io/mbti/


## 이런 기능이 있어요

- 20문항 검사 → 16가지 유형 결과
- 성격 그래프, 강점, 키울 점(오늘의 미션), 어울리는 직업, 공부법, 친구 관계
- 선생님의 편지(봉투를 누르면 열리는 팝업)
- 16가지 유형 도감
- 반별 결과판 · 백업 저장/합치기 (결과는 각자 컴퓨터에만 저장돼요)

## 반마다 다른 링크로 나눠 주기

주소 뒤에 `?class=반이름` 을 붙이면 그 반으로 바로 열립니다.
메신저에서 링크가 끊기지 않도록 **띄어쓰기 없이** 적어 주세요.

```
https://ljakdk.github.io/mbti/?class=3학년2반
https://ljakdk.github.io/mbti/?class=4학년1반
```

## 안내

- 정식 MBTI 검사가 아니라, 자기 이해를 돕는 **교육용 놀이 활동**입니다.
- 좋은 유형·나쁜 유형은 없습니다. 결과로 친구를 놀리지 않도록 함께 약속해 주세요.
- 이름과 결과는 **인터넷으로 전송되지 않고** 사용한 브라우저에만 저장됩니다.
